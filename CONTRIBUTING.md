# Contributing

1. Branch from `main`: `feat/<topic>`, `fix/<topic>`, `docs/<topic>`.
2. Use [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`, `refactor:`, `chore:`).
3. Run `npm run lint` and `npm run build` before opening a PR.
4. Keep PRs focused and fill in the PR template.
